Bloomweave is a turn-based garden path puzzle: click tiles to turn them and weave a continuous path from the garden gate to the bloom. Every turn counts, so plan each rotation before the path runs dry. Runs offline in the desktop browser, keyboard and mouse, no network needed.

## Run it

```sh
node serve.ts
```
